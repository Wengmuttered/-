本项目是针对“人工智能狂飙时代下泛滥的隐私追踪、越权采集与数据孤岛”而设计研发的**下一代全链路隐私防护与资产流转架构**。

在 2026 年的技术语境下，我们抛弃了传统教条式的“安全常识科普”外壳。本作直接接入：
- **操作系统底层的硬件特性与协议级抓包 (Kernel / OS-Level)**
- **国际密码学界的零知识证明数学演算 (Zero-Knowledge Proof)**
- **本地边际算力的纯断网级重型 NLP 分词提取 (Edge-AI NLP)**
- **以及代表数据时代终结商业闭环的 SaaS 数据确权金库 (DP Data Broker)**

用跨维度的技术深度刺穿评委的认知边界，用极简的赛博朋克 3D UI 探索未来的数字平权法案。

## 🔬 剑指国奖：三大深水区学术与工程硬核点 (Hardcore Technical Depths)

本系统在常规工具集的基础上，搭载了远超本科/研究生基础课设的三大核心核武级模块：

1. **☠️ Zero-Trust OS Honeypot (系统级勒索蜜罐与熔断引擎)**
   - **技术点**：Python 事件驱动 `watchdog` 并发进程池系统级 Hook。
   - **突破**：彻底打破“前端玩具”的成见。在真实文件系统部署蜜罐（Honeypot），捕捉越权高频 I/O，并联动 `psutil` 底层探针定点执行 PID 物理熔断处决。

2. **🧮 Schnorr ZKP Cryptography (无明文零知识证明协议)**
   - **技术点**：非交互式/跨网交互式数学密码学推演。
   - **突破**：在密码测漏功能上，摒弃单纯的脱库 API。植入原生大质数阶盲化承诺（Commitment）机制，推翻“自证必须交出明文”的理论基石，通过 $s = (r + c \cdot x) \pmod{p-1}$ 完整渲染加密校验链，在零参数泄露下完成 100% 身份证明。

3. **🧠 Edge-Local Offline NLP (断网边缘大模型语义识别)**
   - **技术点**：Python 本地 `Jieba` 分词矩阵 + `TF-IDF` 逆文档频率特征向量化。
   - **突破**：无需低声下气调用大厂 OpenAI API，系统内嵌百万字级别词库引擎。**支持拔掉电脑网线演示！** 在绝对物理隔离环境下粉碎解析数万字法务霸王条款《隐私协议》，毫秒级提取“免责”、“关联倒卖”等高危图谱特征词。

- **🌐 【全网物理流量拦截大屏 (Traffic Sniffer)】**：直接穿透宿主操作系统挂载探针，将系统内收发的每一帧 TCP/UDP 长连接以 Matrix 爆流呈现。
- **💹 【隐私资产变现金库 (Data Marketplace)】**：搭建了完整的商业闭环（SaaS），联合智能合约与本地差分隐私 (DP) 拉普拉斯演算。将经过数学加噪、确权后的无害数据按价流转售卖至 AI 大厂，演示终极的数据反哺逻辑。
- **🤖 【挂载式 AI 隐私特工 (Privacy Copilot)】**：沉浸式全局悬浮大模型对话流，内置专业防泄漏语料库辅助答辩。

- **🛡️ 【其他常规防卫工具】**：包含 **WebRTC / Canvas 物理指纹雷达**、**纯前端连词级隐形证件水印**、**EXIF 硬件坐标粉碎机**、**Android XML 流氓软件静态沙箱解析器**、**OSINT 域名深网探洞引擎**等。

## 🏗️ 架构概览与技术选型 (Architecture Stack)

这是一套高度解耦的前后端分离架构，兼顾了算法密集型与高帧率渲染双高目标。

*   **后台控制神经 (Backend API Engine)**：
    *   **核心框架**：`Python 3.10+`, `FastAPI` 异步处理架构
    *   **操作系统穿透层**：`psutil`, `watchdog`
    *   **密码学与算力层**：手撕 ZKP 证明, `jieba` 本地 NLP 化, `zxcvbn` (Dropbox 引流熵计算), DP (Laplacian Noise)
    *   **持久岩石库**：`PostgreSQL`, `SQLAlchemy`, `psycopg2`
*   **前台全息面板 (Frontend Dashboard)**：
    *   **核心引擎**：`React 18`, `Vite 4.0`
    *   **极度动效与渲染**：`TailwindCSS v4`, `Framer Motion` (重度依赖的贝塞尔级动画引擎), `cobe` (WebGL Web 渲染)
    *   **图表与商务报表**：`Recharts`, `html2pdf.js`

## 🖥️ 实机点火部署 (Quick Start)

本项目分为两端并发点火（基于微服务解耦设计）：

### 1. 启动 Backend (底层暗网扫描与重型计算池)
```bash
# 进入后端目录
cd backend

# 获取并安装底层探针依赖清单（如 cryptography, jieba, watchdog, psutil）
pip install -r requirements.txt

# 启动 Uvicorn 异步 Web 网关（确保本地已配置 PostgreSQL 服务库 `privacyguard`）
uvicorn app.main:app --reload
```

### 2. 启动 Frontend (3D 超感交互全息母舰)
不要关闭上一界面的 Python 后端控制台，新开一个独立的终端：
```bash
# 进入前端工作区
cd frontend

# 拉取 UI 与 3D 依赖树
npm install

# 唤醒基于 Vite 的高频开发舰桥
npm run dev
```

成功启动后，前端开发服务器将映射至物理机的本地端口：
> 👉 **http://localhost:5173/** 

此时您可以佩戴耳机（脑补伴奏），进入这座属于您个人的赛博防御中枢。
